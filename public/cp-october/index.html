Rules

  1. Before coding, rewrite the statement in one plain line, then work sample 1 by hand. If you can't do both after 15 minutes, read the Note section and the samples again. Understanding the statement is half the problem right now.
  2. Time-box each problem to 45 minutes. Then read the editorial, close it, and code it yourself.
  3. Before you submit, test n = 1, all values equal, the maximum values, and overflow (use long long).
  4. Weekday evening round: do it live if work is quiet. Otherwise do it as a virtual in the next day's 10:45 block, in place of that problem.
  5. CSES stuck past 45 minutes: skip it. You're missing a technique. Come back after the next topic.
  6. Write one line per missed idea in the day's log box.
  7. Missed a day? Don't catch up. Do today's plan and move on.
